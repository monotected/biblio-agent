# ИИ-Агент для автоматизированного бибописания

Настольное приложение с веб-интерфейсом для пакетного извлечения библиографических данных из научных статей (PDF). 
Проект разработан с акцентом на локальную обработку данных с использованием Ollama.

## Возможности
- Пакетная обработка PDF-файлов.
- Локальный ИИ (Ollama), без отправки данных в интернет.
- Визуализация процесса (прогресс-бар).
- Демо-режим для тестирования без ИИ.
- Академический дизайн (шрифты PT Serif/PT Sans).

## Установка и запуск
1. Клонируйте репозиторий и перейдите в папку:
   git clone https://github.com/monotected/biblio-agent.git
   cd biblio-agent

2. Создайте виртуальное окружение и установите зависимости:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

3. Запустите Ollama (например, с моделью llama3):
   ollama run llama3

4. Запустите приложение:
   python app.py

5. Откройте в браузере: http://127.0.0.1:7860
